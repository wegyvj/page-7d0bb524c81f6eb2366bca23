新终端如何开始接入 Ayu？

初次接入只需完成订阅获取、核心配置写入与节点匹配四个步骤。

01

选定并获取订阅链接

根据团队或个人需求确认方案后，从个人管理面板复制专有订阅 URL。订阅串包含了接入地址及安全密钥。

02

导入通用客户端

将订阅 URL 贴入支持相应配置格式的第三方客户端中，触发初次同步以拉取可用节点名单及路由规则。

03

选择分流策略

确认采用规则模式（Rule）还是全局模式（Global）。推荐优先采用规则分流，确保内网及本地流量直连。

04

链路连通性测试

在客户端面板执行延迟测试或节点联通检查，选择延迟较低且响应完整的组别，启动本地代理开关。

终端工具与环境应当如何搭配？

Ayu 输出标准配置参数，用户可根据当前操作系统选用匹配的第三方通用核心。

桌面操作系统 (Windows / macOS / Linux)

建议使用兼容 Clash Core 或 v2ray 核心的桌面客户端。配置时支持通过订阅转换直接下发 YAML 格式配置文件，实现系统级网络代理与指定应用走独立代理的分流方案。

移动移动终端 (iOS / Android)

可通过各应用市场支持订阅协议的工具载入配置。移动网络切换至 Wi-Fi 环境时，请注意开启客户端的“自动重连”与“重载规则”选项以维持会话稳定。

网关与软路由环境 (OpenWrt / Docker)

如需实现全屋或办公局域网透明接入，可将 Ayu 订阅转换为软路由插件支持的配置文件。请注意根据设备 CPU 负载合理设置加密与分流算法。

关于 Ayu 你可能关心的具体细节？

我们汇总了用户在网络分流规则配置、设备数上限与流量重置中最常提出的疑问。

超出同时在线设备数后会发生什么？

当在线连接数超过套餐允许的上限时，系统将遵循后入挤出或阻止新连接发起的机制。若你的团队或家庭有多台设备需要长期常驻，建议调整为容纳 20 台的团队版本，或在局域网网关侧统一进行代理分流。

流量配额是何时重置的？未用完是否结转？

所有档位均按自然月周期或账单开通日进行重置。当月未使用的配额不会累积到下一个计费周期。在达到配额上限后，节点连接将暂停传输，直至周期重置或补购流量包。

为什么部分节点测试正常但网页打不开？

多数情况下与本地 DNS 污染或分流规则未生效有关。建议检查客户端是否开启了“Fake-IP”或系统 DNS 劫持防护，并确认路由模式是否正确设为“规则模式”而非“直接直连”。

基础版与旗舰版在线路上有何实质差异？

基础版配置的是基础线路节点池，适合网页浏览与基础流媒体播放；旗舰版则纳入了专线传输（IPLC）链路，并在游戏联机与高负载场景下做了针对性路由调优，拥有优先工单支持。
